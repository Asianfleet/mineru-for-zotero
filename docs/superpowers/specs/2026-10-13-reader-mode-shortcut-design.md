# 阅读器模式循环快捷键

用户已确认使用一个可配置快捷键循环切换 box 模式，并授权开始实施。

快捷键默认使用 `Alt+Shift+B`，在插件偏好页通过按键录入，可清除绑定；修改立即生效。模式顺序为 `all → hover → off → all`，初始关闭状态第一次切换为全部显示。

每次有效触发先打开当前 PDF 阅读器的 MinerU 菜单，再复用现有模式应用逻辑，完成后重建菜单，以三段模式控件显示实际状态。缺少解析数据时沿用提示和关闭状态。

监听覆盖阅读器及同源嵌套 iframe，绑定随阅读器销毁和插件卸载清理。忽略输入框、可编辑区域、输入法组合输入和长按重复事件；精确匹配修饰键。快捷键不改变其他阅读器状态。

不增加依赖。测试覆盖模式顺序、匹配、输入保护、配置录入与清除、菜单打开及异步结束后的状态刷新。
